## 1. 系统简介

**股你唔到股票分析系统网页版**（页面标题「盯盘雷达」）是一个**单文件网页应用**，定位为**超短线 T+1 交易的信号工具**：

- 打开网页即可用，无需安装 App、无需注册账号、没有服务器后台；
- 支持 **A 股**（沪 / 深 / 北）与 **港股**；
- 行情来自公开数据源（腾讯行情、东方财富、新浪），交易时段自动刷新；
- 内置规则引擎：超短线统一信号、智能信号评分、盘中异动、建仓建议、洗盘/出货、14:50 尾盘观察池、信号台账等；
- 可选接入 **DeepSeek 大模型**：配置一次 API Key，即可让 AI 参与分析，并把 AI 结论合并进「⚡ 超短线信号」；
- **不配置 AI Key 也完全可用**：所有规则功能照常运行，且不产生任何 API 费用。

### 设计理念

1. **唯一信号源**：买不买、卖不卖，只看「⚡ 超短线信号（T+1）」；其它卡片是依据与核对；
2. **规则 + AI 双确认**：规则给数字与纪律，AI 给解读与情景；两者冲突时保守优先；
3. **可解释**：每个结论都能看到数字依据（价位、量能、均线、评分、否决项）；
4. **可验证**：A/B 级信号自动记入台账，观察池次日自动回填验证；
5. **失败不影响主流程**：断网、无 Key、AI 失败、AI 超时，规则功能照常。

## 2. 3 分钟快速开始

### 2.1 打开网页

手机或电脑浏览器访问：

```
https://dengfong3.github.io/hk-radar/
```

### 2.2 添加到主屏幕（推荐，像 App 一样用）

- **iPhone / iPad（Safari）**：底部「分享」→「添加到主屏幕」→ 命名「股你唔到」→ 添加；
- **Android（Chrome / Edge）**：右上角菜单 →「安装应用」或「添加到主屏幕」；
- **电脑（Chrome / Edge）**：地址栏右侧「安装」图标即可安装为桌面应用。

### 2.3 首次使用

1. 在输入框输入股票代码或名称（例如 `300750`、`宁德时代`、`ndsd`、`06166.HK`），点「切换」；
2. 页面自动加载行情、分时、各分析卡片；
3. **先看「⚡ 超短线信号（T+1）」卡**：它给出当前唯一的买卖结论；
4. 若要有 AI 参与：在顶部「AI 深度分析」卡点「配置」，粘贴 DeepSeek API Key（详见第 8 章）。

### 2.4 更新到最新版

- 页面底部显示版本号（当前 `v0.80`），右侧有 **「⟳ 强制更新」** 按钮；
- 手机主屏图标：删除后重新「添加到主屏幕」可拿到最新版；
- 版本较旧时，部分新功能可能不显示。

### 4.1 支持的输入方式

| 输入 | 示例 | 说明 |
|:--|:--|:--|
| A 股代码 | `300750`、`sz300750`、`sh600519` | 沪 / 深 / 北交所 |

### 4.2 行情大卡字段

| 字段 | 含义 |
|:--|:--|
| 现价 / 涨跌 | 最新价与涨跌额、涨跌幅（红涨绿跌） |
| 状态 | 集合竞价前 / 交易中 / 午间休市 / 已收盘 等 |
| 当日均价（VWAP） | 当日成交额 ÷ 成交量，日内多空成本线 |
| 偏离均价 | 现价相对当日均价的百分比，正值越大越“冲高” |
| 今日高 / 今日低 | 日内区间 |
| 成交额 | 当日累计成交金额 |
| 分钟量能 | 最近一分钟成交量相对近期均量的倍数，≥2 表示明显放量 |
| 分时图 | 默认分时；可切换 5 / 15 / 30 / 60 分钟 |

### 4.3 刷新频率

| 场景 | 刷新间隔 |
|:--|:--|
| 正常交易时段 | 约 **15 秒** |
| 股价接近计划档位 / 尾盘时段 | 约 **5 秒**（更灵敏） |
| 集合竞价、午间休市、收盘后 | 约 **60 秒** |
| 日线数据 | 约 **5 分钟** |
| 大盘指数 | 约 **60 秒** |

> 数据来自第三方公开接口，极端行情或接口故障时可能延迟；以券商软件为准。

## 5. 核心信号与十张分析卡

> 除 AI 解读外，以下卡片全部由**本地规则引擎**实时计算，不需要 AI、不消耗费用。

### 5.1 ⚡ 超短线信号（T+1）—— **核心，只看这张**

这是系统**唯一的买卖结论**，把「智能信号 + 盘中异动 + 建仓建议 + 持仓 + AI 分析」合并成一个信号：

```
⚡ 超短线信号（T+1）        现价 266.90  +5.54%
T+1 · 规则 + AI · 10:15
[超短线买入信号]  置信 78   规则 + AI

买点 259.33–262.50   止损 245.26   目标 303.55   RR 2.72
明日卖出计划：次日高开冲高不破均价可持有；平开看量能；低开跌破止损离场
依据：规则买点 + AI 一致（放量突破、多周期共振）
[立即 AI 分析]  [静音 30 分钟]
```

| 信号状态 | 含义 | 该怎么做 |
|:--|:--|:--|
| **超短线买入信号** | 规则买点 + AI 一致，置信 ≥60 | 可考虑按买点区间执行（仍需看盘口确认）；今天买、明天卖 |
| **买点待确认** | 规则买点出现，但 AI 未确认 | 只观察，不执行；等 AI 确认或信号转强 |
| **超短线卖出/减仓** | 规则或 AI 转空 | 有持仓：减仓/离场；空仓：观望 |
| **不交易 / 观望** | 有否决项或条件不足 | 不动手，等下一次信号（不显示执行价位） |

**重要规则**：

- **14:45 后不再提示买入**（T+1 当天无法卖出，避免隔夜风险）；
- **买点弹窗只由本卡触发**；智能信号、盘中异动不再各自弹买入提示；
- 弹窗冷却 10 分钟，避免刷屏；方向转向观望后再次满足条件会重新提示；
- 没配置 AI 时：本卡显示「规则版（未配置 AI）」，同样有结论与弹窗，只是没有 AI 置信度。

### 5.2 下一步买卖点

- **看什么**：按你的「交易计划」给出的减仓档、加仓档、止损位，以及当前价所处位置；
- **怎么用**：没设交易计划时，先到「交易计划」卡点「编辑」，填入减仓档 / 止损 / 加仓档；
- **提示**：系统**不自动下单**，只提示“到了哪一档、该考虑什么动作”。

### 5.3 日内参考位

- **减仓参考**：现价上方的压力位（整数关口、日内前高、枢轴 R1 等）；
- **加仓参考**：现价下方的支撑位（整数关口、均价 −1σ / −2σ、枢轴 P 等）；
- **看什么**：现价处在区间中的位置、距离关键位多远；
- **怎么用**：接近压力位不追高、接近支撑位不恐慌；每个价位都标了“观察”，不是必须成交价。

### 5.4 多周期节奏

- 用 **5 / 15 / 30 / 60 分钟** 四个周期的方向与均线，判断“共振”还是“分歧”；
- **共振偏多 / 偏空**：多周期同向，趋势更可靠；
- **分歧**：多空周期不一致，容易震荡，宜降低操作频率或只做关键位；
- 同时给出各周期 EMA20 参考价。

### 5.5 智能信号（含统一结论）

- **评分**：0～100 分，综合趋势、量价、多周期、盈亏比、仓位等；
- **等级**：A ≥ 75（可执行，需确认）、B 62～74（观察 / 轻仓）、C < 62（无交易）；
- **方向**：long（偏多）/ short（偏空）/ none（无方向）；
- **否决项**：触碰否决项时直接“不交易”，例如周期数据不足、逆势做多、追高、盈亏比 < 2、仓位不足、接近涨跌停等；
- **卡内红字「统一结论」**：显示系统合并后的最终动作与原因，例如
  ```
  统一结论：不交易（震荡区（多周期方向不一致）：不交易；盈亏比 1.67 < 2：不值当）
  ```
- **冲突处理**：若盘中异动出现买点、但统一结论不允许买入，卡内会显示“已屏蔽冲突提示”，且不会弹买点窗；
- **重要**：A/B 级信号会自动记入「信号台账」，用于统计真实胜率。

### 5.6 盘中异动（敏捷信号）

- 监控 **冲高回落、放量、跌破关键位** 等盘中快速变化；
- 每条异动都带：触发原因、时间、参考价、盈亏比 RR、量能倍数；
- **卖出/风控类弹窗**：始终提示（风险优先）；
- **买入类弹窗**：统一收口到「⚡ 超短线信号」，本卡只做依据展示，不再单独弹买点，避免矛盾；
- 只提示、不自动交易。

### 5.7 建仓建议（空仓时）

- 只有在空仓或未设持仓时给出“建仓档 / 止损 / 目标 / 现价 RR / 回踩 RR / 仓位上限”；
- 会给出“不建议建仓”的原因（如趋势向下、盈亏比不足、周期数据不足等）；
- 可点「填入建仓计划」把建议写进交易计划；点「记录到验证清单」进入回测验证；
- **超短线用法**：本卡给出的区间可作为今日买入参考，最终仍以「⚡ 超短线信号」为准；买入后按超短线卡里的“明日卖出计划”处理。

### 5.8 实时分析简报

- **无 AI Key**：显示「简版提示」——一行摘要（现价、评分、压力、支撑、止损、持仓浮盈），点「显示机器简报」可看完整规则版简报；
- **有 AI Key**：默认每 15 分钟生成一份 AI 简报（大字正文 + 风险提示），可点「复制 AI 简报」；「显示机器摘要」可展开规则版核对。

### 5.9 定时深度简报（盘前 / 午间 / 盘后）

详见第 7 章。

### 5.10 洗盘 / 出货检测

- 输出「洗盘分 / 出货分」、特征明细（量能、跌幅、均价偏离、尾盘表现等）与倾向结论；
- 证据不明时明确显示“多空混杂、不据此操作”，不会强行给结论；
- 用于辅助判断“下跌是洗盘还是出货”。

### 5.11 日线 / 盘口 / 大盘

- **日线**：趋势、MA20 / MA60、距均线百分比、MACD、KDJ、20 日区间；
- **盘口**：委比、外盘 / 内盘（A 股）；
- **大盘**：上证、深成指、创业板、沪深300、科创50 等指数涨跌；
- 用于判断“个股与大盘 / 板块的相对强弱”。

## 6. 实时分析简报

「实时分析简报」是系统对当前股票的综合摘要，分两种模式：

### 6.1 未配置 AI Key（规则版）

- 默认只显示**简版提示**：现价、涨跌幅、评分/方向、压力、支撑、止损、持仓浮盈；
- 想看完整规则简报：点「显示机器简报」，会显示「一、实时 / 二、处置建议 / 三、关键位 / 四、明日规则 / 五、一句话」；
- 再点「只看简版」可恢复简洁显示（选择会记住）。

### 6.2 已配置 AI Key（AI 版）

- 简报正文由 DeepSeek 生成，包含总体结论、动作建议、关键位、风险提示；
- 顶部显示生成时间与模型；
- 所有卡片的绿色「🤖 AI：」解读与简报来自**同一次调用**，口径一致。

## 7. 定时深度简报（盘前 / 午间 / 盘后）

这是系统按交易日节奏自动生成的“日更三报”，与实时简报相互独立。

### 7.1 自动生成窗口

| 简报 | A 股窗口 | 港股窗口 | 内容 |
|:--|:--|:--|:--|
| **盘前简报** | 09:00 – 09:30 | 09:00 – 09:30 | 隔夜外盘（美股 / 富时A50）、昨日结构、盘前公告、板块、今日高开/平开/低开三情景策略 |
| **午间简报** | 11:35 – 13:00 | 12:05 – 13:00 | 上午走势（高低 / 均价 / 量能 / 节奏）、午间公告、板块大盘、下午开盘三情景 |
| **盘后简报** | 15:05 – 16:30 | 16:05 – 17:30 | 今日总结（结构 / 量价 / 信号 / 洗盘）、板块大盘、明日三情景策略、风险提示 |

- **只有页面打开时才会自动生成**（省流量、省费用）；
- **周末不自动生成**；
- 错过窗口时显示「已错过自动窗口，可手动生成」，点「立即生成」即可补；
- 每只股票每天三份独立保存，只保留最近 3 个交易日；可「复制」，可「重新生成」。

### 7.2 无 AI Key 时：规则版简报

- 三份简报都会**直接以规则版显示**（按当前行情实时生成，**零 API 调用、零费用**）：
  - 盘前：昨日结构 + 今日关键位 + 开盘三情景 + 信号结论；
  - 午间：上午走势 + 信号与洗盘 + 下午三情景 + 关键位；
  - 盘后：今日总结 + 结构与信号 + 明日初步策略 + 关键位 + 风险提示；
- 每份可「复制」；配置 Key 后自动切换为 AI 深度版。

### 7.3 数据来源与“数据缺口”

- 盘前会额外抓取：**隔夜外盘**（道指 / 纳指 / 标普 / 富时A50）、**交易所公告**（东方财富公告接口，A 股）、板块行情；
- 港股暂无公告接口；某些时点板块数据可能匹配不到；
- **缺失的数据不会写进 AI 正文**：系统只在数据摘要行用小字标「数据缺口：公告、板块」之类；AI 提示词也禁止单独写“数据缺失”小节；
- 目前**没有接入通用财经新闻源**，不会编造新闻。

## 8. AI 深度分析：配置与使用

### 8.1 AI 能做什么

配置 DeepSeek API Key 后：

1. **参与超短线信号**：AI 返回结构化 `ultraShort`（方向 / 置信度 / 买点区间 / 止损 / 目标 / 明日卖出计划），与规则信号合并成「⚡ 超短线信号（T+1）」；
2. **一次调用生成全部卡片解读**：下一步买卖点、日内参考位、多周期节奏、智能信号、盘中异动、建仓建议、洗盘/出货、日线/盘口/大盘、观察池、交易计划，各自在卡片顶部显示绿色「🤖 AI：」解读；
3. **实时分析简报**：AI 版总体结论 + 风险提示；
4. **定时深度简报**：盘前 / 午间 / 盘后三份 AI 深度简报（含隔夜外盘、公告、三情景策略）；
5. **统一口径**：AI 必须服从系统的统一结论（`unified`）：规则“不交易/观望”时，AI 不得给买入建议；发现卡片冲突要指出并收敛。

### 8.2 获取 API Key

1. 打开 DeepSeek 开放平台（platform.deepseek.com），注册 / 登录；
2. 进入「API Keys」→「创建 API Key」，复制以 `sk-` 开头的 Key；
3. 建议：单独创建一个「限额 Key」并充值少量金额（如 10 元），专门给本系统用。

### 8.3 配置步骤

1. 顶部「AI 深度分析」卡，未配置时是折叠的一行，点「配置」展开；
2. 把 Key 粘贴到「DeepSeek API Key」输入框（只存在本机浏览器，不会上传到任何服务器）；
3. 模型默认 `deepseek-v4.1-flash`（可改成 `deepseek-chat` 等）；
4. 点「测试连接」：会发一个最小请求，显示 HTTP 状态、真实模型名、tokens、耗时、Key 掩码——用来确认 Key 有效、调用真实发生；
5. 之后每次 AI 分析成功，顶部会显示上次模型 / tokens / Key 掩码，可和 DeepSeek 后台核对。

### 8.4 三种 AI 触发方式

| 方式 | 说明 |
|:--|:--|
| **手动「立即 AI 分析」** | 顶部「实时跟踪」右侧按钮；超短线卡里的「立即 AI 分析」；右下角悬浮 🤖 →「立即 AI 分析」。点一次调用一次，刷新全部卡片、超短线信号与简报 |
| **自动 15 分钟**（默认） | 勾选「自动15分钟」，每 15 分钟自动分析一次（页面打开时才执行） |
| **实时跟踪**（可选） | 勾选后按事件触发，最短 **90 秒**一次，只在**交易时段**、**页面可见**时执行 |

实时跟踪的触发条件（任一满足）：

- 价格波动 ≥ 0.4%；
- 穿越当日均价（VWAP）或偏离均价变化 ≥ 0.8%；
- 分钟量能 ≥ 2.2×；
- 触及日内新高 / 新低；
- 智能信号评分 / 等级 / 方向变化；
- 洗盘 / 出货结论变化；
- 价格接近减仓档 / 止损位 / 加仓档（0.3% 以内）；
- 大盘波动 ≥ 0.3%；
- 出现新的盘中异动买卖点。

### 8.5 AI 是怎么分析的（原理）

- **一次调用**把所有数据打包成 JSON 发给 DeepSeek：个股（价格 / 均价 / 量能 / 多周期 / 盘口）、日线（趋势 / 均线 / MACD / KDJ / 区间）、板块（行业 / 概念 / 板块资金 / 领涨股）、大盘（5 个指数）、洗盘/出货结论、智能信号评分与否决项、交易计划、持仓、当日观察池、隔夜外盘、公告、规则摘要、**统一结论 unified、交易风格（超短线 T+1）**；
- 系统提示词要求 AI：**必须结合个股 / 板块 / 大盘三层**、引用具体数字与价位、指出矛盾点、缺失数据不编造；**必须服从 unified 统一结论**；**按超短线 T+1 输出可执行的当日买卖点、止损、目标与次日卖出计划**；
- AI 返回一个 JSON，包含 12 个解读字段 + `ultraShort` 结构化信号：
  - 解读：`brief / pricePlan / refs / multiPeriod / signal / burst / entry / wash / macro / pool / tradePlan / risk`；
  - 超短线：`ultraShort = { action(buy/sell/wait), confidence, entryLow, entryHigh, stop, target, nextDayPlan, reason }`；
- 系统按字段分发：解读写入各卡片；`ultraShort` 与规则信号合并成「⚡ 超短线信号」；
- 每张卡片：AI 解读置顶显示，规则数字默认折叠，点「显示规则明细」可展开核对。

### 8.6 模型与失败回退

- 默认模型：`deepseek-v4.1-flash`；
- 若该模型名不可用（400/404 且报 model 错误），自动改用 `deepseek-chat` 重试一次；
- Key 无效 / 欠费 / 限流 / 断网：超短线卡与顶部会显示「AI 失败」及原因，规则卡片不受影响；
- 返回内容不是合法 JSON 时：整段文字作为简报显示，超短线按文字倾向推断，其余卡片无 AI 块。

### 8.7 点击「立即 AI 分析」后会发生什么（状态反馈）

| 阶段 | 卡内显示 |
|:--|:--|

**超时保护**：板块/大盘请求各 15 秒超时；整体 75 秒看护，卡住会自动恢复按钮并提示重试，不会永久失效。

### 8.9 Key 安全（重要）

| 事项 | 说明 |
|:--|:--|
| 存储位置 | 只存在**你浏览器的 localStorage**，不上传服务器、不写进网页源码、不出现在 URL |
| 分享链接给别人 | 别人打开时没有你的 Key → 只能用规则版，**无法使用你的 Key、不会花你的钱** |
| 导出备份 | 新版导出会**自动剔除 Key**；导入不会覆盖你本机的 Key |
| 清除 Key | 顶部 AI 卡「清除」可一键清除（换设备、借人使用前建议清除） |
| 需要注意 | **同一台电脑 / 同一浏览器的使用者**（或会开 DevTools 的人）可以看到 localStorage 里的 Key；不要把浏览器配置文件或旧备份文件发给别人 |
| 旧备份风险 | v0.61 之前导出的旧备份可能含 Key，如果分享过，建议到 DeepSeek 控制台重置 Key |
| 建议 | 使用限额 Key（充值少量）、定期检查用量、不把 Key 贴到聊天群或截图里 |

## 9. 交易计划、持仓与台账

### 9.1 交易计划（本机）

- 点「编辑」可设置：减仓档（T1/T2/T3 各两档价位）、止损位、加仓档；
- 系统据此计算「下一步买卖点」与提醒；
- 计划只存在本机，不上传；换设备需用备份迁移。

### 9.2 持仓（本机）

- 填入股数、成本价、已实现盈亏、本金；
- 自动算：持仓市值、浮盈、盈亏比例、可用资金；
- A 股 T+1、港股 T+0 的提示已内置；
- 用于 AI 与规则判断“有无持仓、是否可减仓 / 加仓”。

### 9.3 信号台账

- 出现 **A / B 级**信号自动记录一条（同一股票同方向 30 分钟内不重复）；
- 后续自动结算，显示「记录 / 结算 / 胜 / 负」与胜率；
- 可「清空台账」（只清本机记录）。

### 9.4 建仓验证

- 从「建仓建议」点「记录到验证清单」进入；
- 次日打开时自动用次日开盘价回填结果；
- 累计几天后可看建仓建议的命中率。

## 10. 观察池、建仓验证与本机数据

### 10.1 14:50 尾盘观察池

- **生成时间**：交易日起 **14:50** 自动生成，窗口内每 3 分钟刷新一次（留出买入时间）；
- **错过窗口**：收盘后打开也会自动补生成一次（用收盘数据）；
- **手动**：随时可点「立即生成今日观察池」；
- **次日验证**：次日打开会自动用开盘价回填昨日名单涨跌，累计看命中率；
- **说明**：这是“今日收盘特征”的排序，**不是明日上涨预测**，不构成投资建议；
- **历史保留**：只保留**最近 3 个交易日**。

### 10.2 本机数据卡

- 显示保存位置（浏览器 localStorage）、当前入口、数据摘要；
- **「导出备份」**：下载 JSON 文件（**不含 AI Key**），可换设备 / 清缓存前备份；
- **「导入备份」**：恢复持仓、计划、台账、观察池、统计等；导入不会使用别人备份里的 Key；
- 不同入口（如 `dengfong3.github.io` 与本地文件）的数据**互不相通**。

## 12. 一天的典型使用流程（超短线 T+1）

### 盘前（09:00–09:30）

1. 打开网页，输入今天要看的股票；
2. 看「定时深度简报 → 盘前简报」（有 Key 为 AI 版，无 Key 为规则版）；
3. 关注隔夜外盘、昨日结构、今日关键位与三情景策略；
4. 若已有「⚡ 超短线信号」买点候选，记下买点区间与止损。

### 盘中（09:30–11:30 / 13:00–15:00）

1. **只看「⚡ 超短线信号（T+1）」的颜色与弹窗**：
   - 出现「超短线买入信号」弹窗 → 看买点区间、止损、目标、明日卖出计划，结合盘口决定；
   - 出现「超短线卖出/减仓」→ 有持仓按计划减仓/离场；
   - 显示“不交易/观望” → 不动手，等下一次信号；
2. 需要核对依据时，再看智能信号（统一结论）、盘中异动、建仓建议；
3. 想更快：勾选「实时跟踪」；否则默认 15 分钟自动刷新；
4. **14:45 后系统不再提示买入**，避免 T+1 隔夜风险。

### 次日（T+1 卖出）

1. 开盘看「明日卖出计划」对应的情景：
   - 高开冲高不破均价可持有，破均价/目标位卖出；
   - 平开看量能与均价，转弱卖出；
   - 低开跌破止损离场；
2. 卖出后重新等下一次超短线买入信号。

### 午间（11:35–13:00）

- 看「午间简报」：上午走势、公告、下午三情景；
- 检查上午是否已触发减仓档 / 止损。

### 盘后（15:05 以后）

1. 看「盘后简报」：今日总结 + 明日初步策略；
2. 需要的话点「立即 AI 分析」生成最新总结；
3. 检查「信号台账」「建仓验证」的累计胜率，回顾执行纪律。

## 13. 常见问题 FAQ

**Q1：为什么页面上的数据是“加载中 / --”？**  
A：刚打开时行情还没到，几秒后自动加载；若持续不加载，点「⟳」强制刷新，或检查网络。

**Q2：超短线信号显示“不交易”，但盘中异动提示买点，听谁的？**  
A：**听「⚡ 超短线信号」**。系统已把异动、智能信号、AI 合并成统一结论：不交易时不显示执行价位，也不会弹买点窗；盘中异动只保留卖出/风控弹窗。卡内如出现“已屏蔽冲突提示”，说明某个买点被统一结论否掉了。

**Q3：点「立即 AI 分析」没反应怎么办？**  
A：v0.80 起点击后卡内会显示状态（启动中 / 分析中 / 完成 / 失败）。若长时间停在“分析中”：75 秒后会自动恢复并提示重试；若显示“AI 失败”，按原因处理（401 Key 无效、402 余额不足、429 限流、网络不可达、模型名错误会自动回退 `deepseek-chat`）。

**Q4：AI 显示“连接失败”怎么办？**  
A：看提示原因；可点「测试连接」再试。若测试连接成功但后台无记录，核对后台 API Key 筛选项是否就是你页面里的 Key（顶部显示 Key 掩码）。

**Q5：分享网页给别人，对方能用我的 Key 吗？**  
A：**不能**。Key 只在你本机浏览器；对方打开后没有 Key，只能使用规则版；备份文件也不再包含 Key。

**Q6：换手机 / 清缓存后数据没了？**  
A：本机数据只存浏览器，清缓存会丢；请提前用「导出备份」，新设备「导入备份」恢复。

**Q7：为什么 14:45 后不提示买入了？**  
A：本系统定位超短线 T+1（今天买、明天卖）；14:45 后买入当天无法卖出，隔夜风险大，所以系统主动关闭买入提示。

**Q8：AI 分析一次多少钱？**  
A：一次全卡分析约 0.5～1 万 tokens；只开自动 15 分钟约 16 次/天。页面有「今日 tokens / 估算费用」，以 DeepSeek 控制台为准；建议限额 Key。

**Q9：为什么有些卡片显示“不交易 / 不建议建仓”？**  
A：规则引擎检测到否决项（周期不足、逆势、追高、盈亏比不足等）。这正是纪律工具的意义：**没把握时明确说不做**。

**Q10：为什么不显示新闻？**  
A：系统目前只接了交易所公告、外盘行情、板块与量价数据，**没有接通用新闻源**（避免编造）。

**Q11：AI 会不会乱说？**  
A：提示词已要求“只依据提供数据、禁止编造、服从统一结论”，但大模型仍可能出错；所有 AI 内容仅供参考，务必用规则数字与券商行情核对。

**Q12：能不能自动下单？**  
A：不能。本系统只做提示与记录，不连接券商、不下单、不代客理财。

**Q13：手机怎么像 App 一样用？**  
A：Safari 分享 → 添加到主屏幕；Chrome 菜单 → 安装应用。

**Q14：如何确认是最新版？**  
A：页脚显示版本号（当前 v0.80）；点「⟳ 强制更新」可强制拉取最新缓存。

**Q15：多个股票怎么快速切换？**  
A：输入代码 / 名称 / 拼音首字母后点「切换」；所有卡片按新股票重算，超短线信号与 AI 解读也会切换。
